# clinical-decision-support-demo

Static demo site for the CPS Integration Lab clinical decision support systems.

**Live site:** https://cpsintegrationlab.github.io/clinical-decision-support-demo/

## Contents

- `index.html` — single-page site, no build step, plain HTML/CSS/JS
- `PALS-simulation.mp4` — PALS (Pediatric Advanced Life Support) simulation walkthrough
- `psepsis-demo.mp4` — OSF PSepsis bundle guidance walkthrough
- `assets/*.jpg` — poster frames shown behind the play buttons

## Local preview

```sh
python3 -m http.server 8000
# open http://localhost:8000
```
